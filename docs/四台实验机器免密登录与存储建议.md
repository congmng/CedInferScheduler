## 项目内文件分层

推荐在可用项目根目录下分为：

- code：本项目控制器及固定版本的 vLLM/LMCache 源码。
- envs：独立 Python 环境。
- models：模型权重；优先复用已有完整模型，避免重复下载。
- datasets：请求 trace 和数据集。
- cache/huggingface、cache/pip、cache/torch：下载和编译缓存。
- kv：有容量上限的 LMCache 磁盘后端，实验结束后按策略回收。
- runs：按实验 ID 分目录记录配置、指标和日志。
- tmp：安装、编译和运行临时文件。

安装前将 HF_HOME、PIP_CACHE_DIR、TORCH_HOME、TMPDIR 指向项目目录内对应子目录，防止默认写满 home 或 /tmp 所在系统盘。LMCache 磁盘路径通过所选版本的配置单独设置；内存后端还需检查 RAM，本次未测内存容量。

4090 的 /mnt/home 可作为主要开发与实验存储；67.68 的 /data/sdb 适合模型、trace 与归档副本。3090 节点块设备报告 ROTA=1，但可能经过虚拟化，不据此认定实际介质性能。跨域实验中的网络与存储带宽均需另测，不能由 IP 段或 df 容量推断。

本次仅变更免密登录所需的公钥与目录权限，并新增本地会话连接配置和此报告。未清理既有数据、迁移模型或创建实验目录。
